Get the Python v2 language on your machine. It is free, open source, and needs nothing but Python 3.10+. Version 0.3 also includes the dependency-free PyHope game engine— no pygame required.

03 Install on Your Machine

One requirement: Python 3.10 or newer (python.org/downloads). Python v2 itself has zero dependencies.

macOS & Linux

# 1. check your Python (macOS ships python3; Linux: apt/dnf install python3)
python3 --version        # need 3.10+

# 2. get the language
git clone https://github.com/gefrus112/pythonv2
cd pythonv2

# 3. verify the install
python3 -m pyv2 --version
# Python v2 0.3.0

# 4. run your first program
python3 -m pyv2 examples/hello.pyv2
# Hello, World!
# 2 + 2 = 4

Windows

# Option A — plain PowerShell / cmd
py --version             # install from python.org if missing
git clone https://github.com/gefrus112/pythonv2
cd pythonv2
py -m pyv2 examples/hello.pyv2

# Option B — WSL (recommended): install Ubuntu from the
# Microsoft Store, then follow the macOS & Linux steps.

Make it your own

Add a shell alias so you can just type pyv2:

# macOS / Linux — add to ~/.zshrc or ~/.bashrc
alias pyv2='python3 -m pyv2'

# now:
pyv2 examples/fib.pyv2
pyv2                      # REPL!

FAQ

QuestionAnswer
Is there a pip install? Not yet — clone and run. There is literally nothing else to install.
Does it replace my Python? Nope. Python v2 lives in its own folder and runs on top of Python 3. Nothing to uninstall, nothing breaks.
Which platforms? Anything with Python 3.10+: macOS, Linux, Windows, WSL, Raspberry Pi, dev containers, Codespaces.
How do I update? git pull — then run the tests if you're curious: python3 -m unittest discover -s tests -t .
