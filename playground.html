PLAYGROUND TUTORIAL

From first run to useful project

01

Choose a runtime

Python v2 uses fn, end, lowercase booleans, and readable ternaries. Classic mode accepts familiar def and indentation for its supported subset.

02

Read the terminals

Normal print() text goes to Output. Syntax and runtime failures go only to Problems, with the line and error type.

03

Run commands

The bottom prompt remembers successful variables. Enter expressions such as 6 * 7, assignments, or print(). Use ↑ and ↓ for history.

04

Move to the app

The desktop PyHope workspace adds managed files, offline assets, projects, editor connections, settings, and local website previews.
