PYHOPE GPU RAYCASTER • WEBGL2

Over nine million ray-cast pixels

Live mode runs at 1280×720. The opt-in 9M frame button resizes the real GPU canvas to 4096×2304 and ray-casts 9,437,184 fragments. It renders one still frame so small devices do not melt.

GPU • WEBGL2
Honest benchmark: this is not CSS upscaling. In 9M mode, canvas.width × canvas.height is exactly 4096 × 2304. Ray work and the large framebuffer stay on the GPU instead of a 9-million-item Python list. It is memory-efficient—not “zero RAM,” because every real browser and game needs memory.

The level really comes from Python v2

When this page starts, the browser interpreter runs the script below. Its printed rows become Comet Hopper's level. That is a deliberately small first bridge between the language and PyHope; the engine APIs, physics, sprites, and renderers are all open source.

level = [
    "........................................",
    "...........................C............",
    ".............C...........####...........",
    ".........#####..........................",
    "..C..................M.................F",
    "#####...........########..............###",
    "........................................",
    "########################################",
]

for row in level:
    print(row)
end
