No More Indentation Wars

            
Blocks open with : and close with end.
              Tabs, spaces — do whatever. The compiler doesn't care. Your team won't either.

          

          

            
ƒ

            
Real Closures

            
Assignment finds the variable that already exists, wherever it lives.
              Counters that count. No nonlocal incantations required.

          

          

            
“”

            
F-Strings, Solved Forever

            
f"Hello, {name}!" — interpolation that just works,
              expressions and all. The old way of concatenating strings is cancelled.

          

          

            
?

            
Forward Ternary

            
ok ? "yes" : "no" reads left to right, like your eyes do.
              Wild concept. Also: + joins strings and numbers without a lecture.

Get Started in 30 Seconds

        
Python v2 is free, open source, and lives on GitHub.
          Clone it and run — no install step, no virtualenv, no drama.


        

          

            
1. Grab the runtime

            
git clone https://github.com/gefrus112/pythonv2
cd pythonv2

            
2. Run something

            
python3 -m pyv2 examples/hello.pyv2

            
3. Or just talk to it

            
python3 -m pyv2
>>> print(f"{'2' * 3}")
222

          

          

            
Your first program

            
# hello.pyv2
fn greet(name):
    if name == "":
        return "Hello, stranger!"
    end
    return f"Hello, {name}!"
end

for who in ["World", ""]:
    print(greet(who))
end

Documentation

        
The whole language fits on one page. (The reference implementation
          is on GitHub — about 1,500 lines
          of Python and its JavaScript twin.)


        

          

            
print(...)

            
Print any number of values, space-separated.

            print("sum:", 1 + 2)
          

          

            
f-strings

            
Interpolate any expression with braces.

            f"{name} scored {score * 2}"
          

          

            
fn / end

            
Functions are values. Closures capture properly.

            fn add(a, b): return a + b end
          

          

            
if / elif / else

            
Blocks end with end, not a column number.

            if x > 0: print("pos") end
          

          

            
while / break / continue

            
The usual loop verbs, no surprises.

            while true: break end
          

          

            
for … in

            
Iterate lists, strings, maps and ranges.

            for i in range(1, 10, 2): print(i) end
          

          

            
lists

            
[1, 2, 3] with methods that spark joy.

            xs.push(4)  xs.sort()
          

          

            
maps

            
Bare keys, dot access, safe get.

            hero = {name: "Ada"} → hero.name
          

          

            
ternary

            
Condition first, like a question should be.

            status = ok ? "yes" : "no"
          

          

            
builtins

            
len, range, type, str,
              int, sort, join, assert, …

            print(type(2), len("abc"))
          

          

            
string methods

            
upper, split, replace,
              trim, contains, slice, …

            "a,b".split(",").join("-")
          

          

            
numbers

            
+ − * / // % **, floored mod, real division.

            print(7 // 2, -7 % 3, 2 ** 10)
          

        

        
Full spec, grammar and builtin reference:
          docs/LANGUAGE.md
